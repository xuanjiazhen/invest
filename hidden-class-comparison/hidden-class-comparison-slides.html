Transition 机制对比

ArkVM — 线性链表

HClass₀
└─Transition→ HClass₁ (添加 "x")
  └─Transition→ HClass₂ (添加 "y")
    └─Transition→ HClass₃ (添加 "z")

每次 add property: Clone JSHClass（88B）
查找: O(n) 线性遍历
不共享 Layout

V8 — 树形 TransitionArray

Map₀
├─ TransitionArray["x"] → Map₁x
├─ TransitionArray["y"] → Map₁y
└─ TransitionArray["z"] → Map₁z

每次 add: CopyReplaceDescriptors (共享数组)
查找: Hash/Trie O(1)
同 shape 共享 DescriptorArray
