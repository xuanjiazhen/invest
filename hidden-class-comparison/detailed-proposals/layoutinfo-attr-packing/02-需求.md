# LayoutInfo 属性描述槽压缩 —— 需求

本文件描述方案收益、工作量与风险，供项目管理者与评审决策。

## 1. 方案目标

把 `LayoutInfo` 每属性的 Attr 存放从 8 B tagged 槽改为原始位区（分离双区：Key 区 8 B tagged + Attr raw 区）。**Attr 槽实际载荷最多 41 bit**（28 bit 布局真值 + 10 bit SortedIndex + 3 bit 标志，见 01-背景 §3.1），压缩分两档：

- **A 档（6 B raw，无损等价）**：全 41 bit 原样进 6 B 区，每属性 16 B → 14 B；
- **B 档（4 B raw，目标形态）**：迁移 13 个运行时位（SortedIndex 10 bit + IsConstProps/IsNotHole/IsPGODumped 3 bit）后仅存 28 bit 布局真值，每属性 16 B → 12 B。

## 2. 收益（两档，Top13 全量逐数组精算，含对齐）

| 档位 | 精算收益 | 说明 |
|---|---|---|
| A 档 6 B（无损） | **10.42 MiB / 9.5%**（109.25 → 98.83 MiB） | 14 B/属性与 8 B 对齐相互作用，N=1..3 档 padding 吃掉大半节省 |
| B 档 4 B（迁移 13 位后） | **23.17 MiB / 21.2%**（109.25 → 86.08 MiB） | 相对朴素模型仅损 1.35 MiB（N 奇数时 4 B padding；N≤1 的 75,170 个零节省）；**依赖 SortedIndex/标志迁移设计落地** |

- 与 JSHClass AuxData Sidecar 叠加：同对象族不同数组，收益可叠加；同批版本 bump 共用一次 clean rebuild；
- 收益边界：浅层堆口径，不含 Region 空洞与 PSS；放行以 clean A/B 实测为准；
- 档位对照 V8：B 档 12 B/属性追平 V8 指针压缩后的 DescriptorArray 条目宽度；A 档 14 B 仍有差距。

## 4. 风险

| 风险 | 等级 | 控制条件 |
|---|---|---|
| LookupProperty 热路径性能回退（Attr 地址计算复杂化） | 中 | 双区布局保持各区内连续；解释器 + AOT 两条查找链基准，回退阈值 ≤1% |
| AOT 固定偏移读取失配 | 中 | 与 AuxData Sidecar 同批 bump `.an/.ai` 版本，clean rebuild，新旧产物双向拒绝 |
| 属性数与 Attr 区长度一致性 | 中 | 长度字段单一来源 + heap verification 断言 |
| Attr 区越界（raw 区不被 GC 感知） | 中 | 哨兵对象压力 GC 用例（Attr 区末尾后放哨兵，验证不被覆写/误扫） |
| B 档 SortedIndex 迁移：索引服务按 hash 二分查找与枚举序（`AddKeyCommon` 维护） | 高 | 迁移方案三选一冻结：独立 u16 索引区（4+2=6 B，收益回落至 A 档）/ Key 区改为 hash 有序（V8 式，查找与枚举序联动重审）/ 按需重算；未冻结前 B 档不进入开发 |
| B 档标志位迁移（IsConstProps/IsNotHole 语义位、IsPGODumped 瞬态位） | 中 | 语义位折进 SharedFieldType 空余编码或随 SortedIndex 方案一并安置；IsPGODumped 改 PGO 侧会话级去重集合（堆外） |

## 5. 验收门槛（摘要）

- 尺寸公式按档位：A 档 `align8(16 + 14N)`、B 档 `align8(16 + 12N)`；Top13 新快照逐数组符合公式，A 档总降幅 ≥9 MiB、B 档 ≥20 MiB；
- 属性查找/transition/枚举/AOT/PGO/序列化全回归通过；LookupProperty 微基准与属性访问 IC 回退 ≤1%；
- GC 矩阵（young/old/full/CMC）+ heap verification + 哨兵越界用例通过；
- PSS 中位数不回退；与 AuxData Sidecar 合批时新旧产物双向稳定拒绝。

## 6. 依赖

- 无新编译宏依赖；与 ≤6G JIT/AOT-off 分档正交（布局压缩对档位无感知）；
- 版本契约与 `jshclass-auxdata-sidecar` 建议同批（一次 clean rebuild 覆盖两项）。
