# 对象字面量外置 Backing COW —— 需求

## 1. 方案目标

仅优化对象字面量创建路径：对满足白名单的外置 `Properties` / `Elements` backing 使用现有 `COWTaggedArray` 表示，使模板与未发生写入的对象字面量实例共享初始 backing；实例首次写入前复制为普通私有 backing。

必须保持：

- 每次字面量执行仍返回独立 `JSObject`；
- 属性值、属性描述、枚举顺序、原型和异常行为不变；
- 方法、getter/setter 的 `LexicalEnv` / `HomeObject` 仍按实例克隆和重绑；
- interpreter、AOT/runtime stub 和无优化路径行为一致。

## 2. 非目标

- 不做 ConstantPool 字符串跨 VM 共享；
- 不改数组字面量及普通数组 COW；
- 不共享 HClass，不改 shared heap / worker 生命周期；
- 不改字节码、abc、snapshot 持久化格式；
- 不做模板克隆或编译期字面量重写；
- 不对 inline properties 做 COW。

## 3. 收益口径

对每个可共享 backing `i` 定义：

- `B_i`：对齐后的 backing 字节数；
- `N_i`：对象字面量克隆次数；
- `W_i`：发生首次写脱离的克隆数，`0 <= W_i <= N_i`。

若模板在创建时直接使用 COW backing，则事件累计口径为：

```text
避免的克隆分配字节 = Σ(N_i × B_i)
首次写复制字节       = Σ(W_i × B_i)
事件净减少字节       = 避免的克隆分配字节 - 首次写复制字节
```

该公式不等于快照时刻的 live shallow 收益，也不包含 NON_MOVABLE 碎片、Region 提交和 RSS/PSS。正式收益必须并列报告：

1. 克隆次数、共享字节、首次写率和复制字节；
2. clean A/B full-GC 后 shallow live bytes；
3. Region used / committed；
4. 峰值与稳态 RSS/PSS；
5. 创建热路径和首次写热路径耗时。

现有快照没有 clone/write provenance，当前净收益记为**未量化**，不得使用 83.69 MiB `js_object` 总量或 Kuaishou 的混合 JSObject/JSArray 驻留域代替。

## 4. 首版白名单

`Properties` 与 `Elements` 独立判定，满足以下条件才进入 COW：

1. 来源是 ConstantPool 对象字面量模板；
2. backing 非空、为 fast `TaggedArray`，不是 dictionary；
3. 长度不超过插桩确定的阈值；
4. backing 不含需要按实例克隆或重绑的 `JSFunction` / `AccessorData`；
5. 运行在同一 VM 本地堆，不跨 VM / shared heap；
6. runtime 与 compiler stub 均支持写前脱离。

任一条件不满足时维持现有深拷贝。

## 5. 验收门槛

1. 所有对象属性/元素写路径在修改 COW backing 前完成脱离；静态审计不存在可达的直接原地写遗漏。
2. 方法、getter/setter、`super`、枚举顺序、descriptor、symbol key、数值 key、删除、扩容和 dictionary 转换语义不变。
3. Runtime 两个 `CloneObjectLiteral` 重载与 compiler stub 输出一致。
4. 插桩给出对象字面量独立数据：clone 次数、eligible/fallback、共享字节、首次写率、复制字节和 fallback 原因。
5. clean A/B DT、UT、解释执行、AOT、full-GC、heap dump 和压力测试通过。
6. 事件净减少字节为正，且 clean A/B 的 shallow 与物理内存结果分别报告；无数据时不进入默认开启。
7. 关闭开关时完全回到原深拷贝路径。

## 6. 风险

| 风险 | 等级 | 控制条件 |
|---|---|---|
| 普通 `JSObject` 写路径遗漏，导致实例间数据污染 | 高 | 统一 owner-aware 脱离 helper；审计 runtime/stub/AOT 直接写；故障注入验证 |
| 函数或访问器槽被错误共享，破坏 `HomeObject` / lexical env | 高 | 首版白名单排除需实例化重绑的 backing；保留原克隆路径 |
| 首次写率高，COW 检查与复制使性能或内存退化 | 高 | 插桩门槛；按 backing 长度和字面量点位分桶；运行时开关回退 |
| NON_MOVABLE backing 增加碎片或 committed 内存 | 中 | 限长；单列 Region used/committed 与 RSS/PSS；不以 shallow 替代物理收益 |
| Runtime 与 compiler stub 行为分叉 | 高 | 共用 eligibility/脱离语义；解释态、AOT 与 stub 对拍 |
| dictionary、扩容、elements-kind migration 破坏 COW | 高 | 进入转换前先脱离或直接分配新 backing；专项 DT 覆盖 |

## 8. 依赖

- 复用现有 `COWTaggedArray` 类型和 NON_MOVABLE 分配机制；
- 需要 owner-aware 的普通对象 backing 脱离入口；
- 需要 `CloneObjectLiteral` runtime/stub 插桩及 clean A/B 采集环境；
- 不依赖 worker、shared heap 或字符串表改造。
