# 架构决策记录（ADR）：字符串优化

## 状态
提议（待构成拆解后确认收益）。

## 背景
string 83 MiB 是第四大占用类别，已有压缩 + intern 基础，机会点明确。

## 决策
先做**构成拆解**（长度分布 + LineString/Tree/Sliced/External 占比 + intern 命中率），再按收益排序选择短字符串内联或 intern 补全。

## 权衡
| 子方向 | 潜在收益 | 实现成本 |
|---|---|---|
| 短字符串内联 | 高（短 key 数量大） | 中（改字符串分配布局） |
| intern 补全 | 中（重复字符串去重） | 低（改 intern 调用点） |
| TreeString flatten | 中（拼接结果长期持有） | 低（flatten 时机） |
| SlicedString 父串弱持 | 低（小切片场景少） | 高（父串生命周期） |

## 影响
- 影响字符串分配热路径；需 GC/序列化回归。
