# 插桩设计：ProfileTypeInfoCell 按需分配

## 目的

获得生命周期内可避免分配比例 `e`，验证父 slot 共享拓扑，并计算延迟绑定元数据成本 `M`。不得从单次 snapshot 的 `CELL_0` 比例推导 `e`。

## 计数器

| 计数器 | 触发点 | 含义 |
|---|---|---|
| `cell_alloc_definefunc` | DEFINEFUNC 创建实际 cell | 基线分配数 |
| `cell_alloc_template` | FunctionTemplate 创建实际 cell | 基线分配数 |
| `cell_reuse_same_slot` | 父 slot 已有 cell | 同 slot 复用次数 |
| `cell_first_value_write` | Empty/Undefined 首次写 `Value` | 首次反馈事件 |
| `cell_first_pgo_touch` | 首次写/读 define-class `Handle` | PGO 首触发事件 |
| `cell_exit_never_triggered` | 进程退出或 VM 销毁对账 | 生命周期内无反馈且无 PGO 触碰的候选数 |
| `cell_parent_slot_resolve_ok/fail` | 原型首次触发 | 父 profile/slot 定位成功率 |
| `cell_duplicate_for_same_slot` | 原型一致性检查 | 同一父 slot 建立多份 cell，必须为 0 |
| `deferred_binding_count/bytes` | 原型元数据分配 | 成本 `M` |

计数应按主线程/worker、DEFINEFUNC/FunctionTemplate、PGO 开关和 cell 复用级别分桶；对象身份只用于进程内对账，不写入持久日志。

## 输出指标

```text
N = cell_alloc_definefunc + cell_alloc_template
avoidable = cell_exit_never_triggered
e = avoidable / N
M = deferred_binding_bytes
lazy_gross_bytes = 32 * avoidable
lazy_net_bytes = lazy_gross_bytes - M
```

还需输出：父 slot 解析失败数、重复 cell 数、首次反馈/PGO 延迟分布、创建路径耗时，以及前后台生命周期分别统计的结果。

## 验证用例

1. 同一 slot 连续创建多个闭包，按不同顺序触发 IC 和 PGO；
2. 首次触发前后插入 young/old/full/CMC GC；
3. worker、async/generator、FunctionTemplate、AppSpawn 路径；
4. PGO 开/关、AOT/JIT 开/关组合；
5. 原型快照 cell 节点下降量与 `avoidable` 对账；
6. 临时插桩关闭后构建产物不残留计数器、字符串或日志分支。

## 放行门槛

`cell_parent_slot_resolve_fail=0`、`cell_duplicate_for_same_slot=0`、全能力回归通过且 `lazy_net_bytes>0`。否则保持现有即时分配。
