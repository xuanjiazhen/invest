异步 defer：返回之前完成清理

  • 更新　异步作用域退出可以等待清理
  • 收益　减少多出口遗漏与"清理尚未完成"的竞态
  • 边界　等待清理不等于屏蔽取消
自编语义示意 · 未运行SE-0493 · 6.4 已实现提案
func performJob() async throws {
    await acquireResource()
    defer { await releaseResource() }
    try await executeJob()
}

离开作用域时隐式等待；多个 defer 仍逆序运行。
