# WWDC 2026 语言、编译器、工具链与 Xcode 更新调研计划

## 调研范围

记录 WWDC 2026 及 Swift 6.3、Swift 6.4、Xcode 27 的公开更新，覆盖 Swift 语言表达、所有权与标准库、编译器、Swift Build 与互操作、Xcode 的 Agent、测试、设备与性能诊断。

## 事实记录规则

- 语言能力以 Swift Evolution 提案、Swift 官方发布说明和语言文档为依据。
- Xcode 能力以 Apple Developer 的会议资料、发布说明和产品文档为依据。
- 每项记录注明版本、功能状态和适用边界；不将大会年份、工具链版本和平台 SDK 版本视为同一版本号。
- 不把设计材料中的目标、示例或性能说明扩展为未验证的产品结论。

## 交付件

- `req.spec.md`：原始需求。
- `plan.spec.md`：范围、来源和验收规则。
- `report.spec.md`：附官方可追溯链接的事实报告。
- `wwdc2026-language-compiler-toolchain-slides.html`：与报告术语和来源一致的交互式幻灯片。
- 根目录 `index.html`：仅提供该 slides 的入口。

## 验收标准

- 报告和 slides 只陈述可由公开来源直接核验的能力、版本、结构、状态和限制。
- 报告与 slides 不含趋势判断、优劣评价、选型建议、行动建议或制作记录。
- slides 支持键盘与按钮导航，并可在桌面与移动视口显示。
- 根索引只链接 HTML slides，不链接 Markdown 或其他产物。
