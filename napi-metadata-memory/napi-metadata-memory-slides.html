已知优化方向（源码分析）

IC feedback 惰性初始化

不在函数创建时预分配 1-8 KB vector，参考 V8 在首次调用点按需分配。预计每个 method 节省 80-90%。

JSHClass 瘦身

128B → 64B：合并冗余 BitField 位域、压缩 Layout descriptor 指针。预计 HClass 链节省 50%。

SemiSpace 细粒度

Region 从 256 KB → 64 KB 步进，避免小 class 触发大 chunk 分配。

批量 property 注册

一次性创建带全部 inline props 的 HClass，替代逐个 transition。
