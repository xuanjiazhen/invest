MLIR 与公开方言项目

MLIR

核心对象：Dialect、Operation、Region、Block、Value、Type、Attribute。

用途：定义多层表示、Pass、验证和方言转换。

CIR

Clang 的 MLIR 方言，位于 Clang AST 与 LLVM IR 之间，输入为 C/C++。

ONNX-MLIR

使用 ONNX、Krnl 等方言导入 ONNX 模型并生成目标代码。

Torch-MLIR

使用 Torch、Linalg 等方言导入 PyTorch 图并向下层方言转换。

源码与字节码分析、转换

Soot Jimple

输入：JVM bytecode、Android DEX。

结构：有类型、无栈三地址码。

用途：调用图、数据流、指针分析、插桩和转换。

WALA IR

结构：方法级 SSA 寄存器传送表示。

用途：调用图、指针分析、切片和数据流分析。

Clava 程序模型

输入：C/C++ 源码。

结构：Clang AST 上的 joinpoint API。

用途：源码查询、变换和再生成。

Soot IR 家族

Shimple：Jimple SSA 形式。

Baf：栈式表示。

Grimp：聚合表达式表示。

CompCert IR 家族

Clight、Cminor、RTL、LTL、Mach 等多级表示。

用途：定义操作语义并验证编译转换。

CIL

输入：ANSI C 及多数 GNU C、Microsoft C 扩展。

将 C 归约为较少的核心构造，同时保留类型与源码关系。

Soot/SootUp · WALA IR API · Clava · CompCert Documentation · CIL Documentation

二进制提升与机器码分析

Ghidra P-code

由操作码与 varnode 构成的寄存器传送语言。

raw p-code 用于仿真；high p-code 带 SSA 信息。

VEX IR

类型化临时值、表达式、语句与 IRSB 基本块。

Valgrind 用于动态插桩，angr 用于跨体系结构机器码分析。

BAP IR / BIL

架构无关程序表示及传统指令语言。

用于控制流恢复、符号执行和程序分析。

REIL

精简指令集形式的中间语言，用于 BinNavi 二进制分析。

BinNavi 仓库已归档并停止主动开发。

Ghidra P-code Reference · Valgrind VEX · angr IR · BAP Handbook · BinNavi REIL Reference

图式程序模型与验证表示

Code Property Graph

带类型节点、带标签有向边和键值属性的有向多重图。

在同一结构中保存语法、控制流和过程内数据流。

用于图查询、程序模式检索和漏洞发现。

Boogie IVL

Dafny、VCC、SMACK、GPUVerify 等前端可生成。

Boogie 工具生成验证条件并交给 SMT 求解器。

WhyML

包含逻辑声明、程序类型、循环、异常、契约和不变式。

生成验证条件并调用 SMT 求解器或交互式证明器。

CPG 是图式程序模型；Boogie IVL 与 WhyML 是面向验证的语言和程序模型。

Joern CPG Documentation · Boogie Documentation · Microsoft Research · Why3 Documentation

TVM

SPIR / SPIR-V

SPIR 基于特定 LLVM bitcode 版本；SPIR-V 是 Khronos 二进制中间语言标准。

历史与研究型 IR

WHIRL

Open64 的多层树形 IR；公开前端包括 C、C++、Fortran。

SUIF1 / SUIF2

Stanford SUIF 的研究表示，用于循环、并行化和依赖分析。

COINS HIR / LIR

COINS 的高层与低层表示，公开输入包括 C、Fortran。

HSAIL / BRIG

HSAIL 文本格式及其二进制表示 BRIG；HSA Foundation 官方归档仓仍可访问。

OpenCL SPIR

OpenCL C 到特定 LLVM bitcode 版本的标准映射。

Open64 · Stanford SUIF · COINS · HSA Foundation · Khronos SPIR
